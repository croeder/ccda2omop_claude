# CCDA2OMOP_Claude is an experiment using Claude Code to write a CCDA to OMOP converter.

## All test data here is Synthetic

I spent as much as $30 on Claude and less then 4 hours of my own time building this system. It's not as complete as our other effort, but consider the time. Consider also that the prompting has benefitted greatly from the experience of writing the Python version.


See the prompt_log.txt file for the prompts used. More doc.s from Claude are in DEVELOPMENT_LOG.md and the git commit messages.
