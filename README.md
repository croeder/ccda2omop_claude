# ccda2omop_claude
This is an experiment using Claude Code to write a CCDA to OMOP converter in golang.

## All test data here is Synthetic

I spent as much as $50 on Claude and less than 20 hours of my own time building this system. It's not as complete as our other effort, but consider the time. Consider also that the prompting has benefitted greatly from the experience of writing the Python version.

This will change many things.


See the prompt_log.txt file for the prompts used. More doc.s from Claude are in DEVELOPMENT_LOG.md and the git commit messages.
